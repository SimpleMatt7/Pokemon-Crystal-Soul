# Testi modificati (italiano, ROM IPKI)

Un file `msg_NNNN.csv` per archivio di testo (NNNN = indice in a/0/2/7, uguale al numero `msg_NNNN` della decomp).
Colonne: `indice`, `testo` (il testo nuovo, scritto da noi, con la sintassi di `tools/msg.py`: `\n` a capo,
`\r` nuova finestra, `\f` scorrimento, comandi tra graffe come `{STRVAR_1 0, 1, 0}`).
Per vedere i testi originali: `python tools/msg.py mostra NNNN [indici]` (non si copiano qui).
Per un'eventuale versione inglese: stessa struttura in `data/testi/ENG/`.
